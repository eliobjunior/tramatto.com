1.3 Descoberta Crítica — Preços Chegam Como Número

O arquivo catalog-data.js armazena preços como strings formatadas ("R$ 120,00"). Porém, o MockAdapter em adapters.js aplica parsePrice() antes de instanciar os objetos de domínio, convertendo para number:

// adapters.js:9–12
function parsePrice(value) {
  const normalized = String(value)
    .replace(/[R$\s]/g, '')
    .replace(/\./g, '')
    .replace(',', '.');
  return Number(normalized) || 0; // "R$ 120,00" → 120
}
Conclusão Todos os preços chegam como number ao dataLayer. Nenhum risco de string em parâmetros numéricos do GA4 ou do Meta Pixel.

3.1 Código de Referência — Fase A

select_item — dispatcher (script.js)

function dispatchSelectItem(product, index, listName = 'Coleção Premium') {
  document.dispatchEvent(new CustomEvent('tramatto:select_item', {
    detail: {
      list_name: listName,
      item: {
        item_id:       product.slug,
        item_name:     product.title,
        item_brand:    product.brand,
        item_category: product.googleProductCategory || product.productType || '',
        price:         product.getPrimaryPrice?.() || product.price || 0,
        index
      }
    }
  }));
}

add_to_cart — dispatcher (script.js)

function dispatchAddToCart(product, variant, quantity = 1) {
  const price = Number(
    variant?.getPrimaryPrice?.() || variant?.price ||
    product.getPrimaryPrice?.() || product.price || 0
  );
  document.dispatchEvent(new CustomEvent('tramatto:add_to_cart', {
    detail: {
      currency: 'BRL', value: price * quantity,
      item: {
        item_id:       product.slug,      item_name:     product.title,
        item_brand:    product.brand,     item_variant:  variant?.name || null,
        item_category: product.googleProductCategory || '',
        price, quantity
      }
    }
  }));
}

4.4 Riscos Identificados

⚠ Médio
Posição GTM em index.html
Snippet GTM na linha 723 do arquivo. Verificar se está dentro do <head> antes da instalação. Se no <body>, o Pixel pode disparar fora do timing correto.
⚠ Médio
content_ids e IDs do Catálogo
Os content_ids no Pixel (slugs como "linho-anatoliano") devem coincidir com os IDs no Catálogo de Produtos do Meta quando criado. Planejar nomenclatura com antecedência.
✓ Resolvido
Preços como string
Inicialmente identificado como risco, mas parsePrice() em adapters.js garante que todos os preços chegam como number ao dataLayer.
